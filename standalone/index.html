Welcome to Observe Tools

A collection of utilities for working with Observe. Select a tool from the sidebar to get started.

Monitors
📋
Export Monitor List
Fetch all monitors and export as a sortable table or CSV.
🔔
Export Monitor Details
Fetch a single monitor by ID and generate a cURL command to recreate it.
📊
Export All Monitor Details
Bulk fetch all monitors with full details, destinations, and copy cURL/PowerShell per row.

Export Dataset

Tools
⬆️
Import File
Send any file or pasted data to Observe via HTTP ingest with gzip compression.
🔓
Base64 Decoder
Decode base64 strings, including Observe copied dashboard format.
🔒
Base64 Encoder
Encode JSON or text as base64 with the Observe dashboard wrapper for easy import.
